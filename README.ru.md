# Lolz Telegram

[English version](README.md)

Бот пересылает новые и поднятые темы Lolzteam в отдельные топики приватной группы Telegram. Подписками и доставкой можно управлять из личной админки.

- Разделы можно искать по названию или добавлять по ID. Бот создаёт отдельный Telegram-топик для каждого раздела и сверяет актуальный раздел темы перед публикацией.
- В публикацию входят название, цена, если её удалось определить, время создания, время последнего поднятия, ссылка и доступный текст первого сообщения. Даты показаны по Москве.
- SQLite сохраняет топики, очередь и прогресс доставки между перезапусками. В админке видны остаток квоты Lolzteam и число запросов по методам API.

## Запуск

Нужен Python 3.10 или новее. Бот использует стандартную библиотеку Python.

~~~bash
cp .env.example .env
~~~

В Windows выполните `Copy-Item .env.example .env` в PowerShell.

Укажите токен от BotFather в `TELEGRAM_BOT_TOKEN` и свой числовой ID Telegram в `TELEGRAM_ADMIN_ID`. Пустые значения бот запросит в терминале при первом запуске. Токен форума Lolzteam с правом `read` можно добавить в `LOLZTEAM_TOKEN` или через админку. [Авторизация Lolzteam](https://lolzteam.readme.io/reference/oauth2)

Добавьте бота администратором в приватную супергруппу с включёнными темами и выдайте право **«Управление темами»**. Укажите `TELEGRAM_GROUP_ID` перед первым запуском или отправьте `/bind` в группе от своего аккаунта администратора после запуска.

Запустите `python3 bot.py` или `python bot.py` в Windows. Откройте личный чат с ботом, отправьте `/start` и выберите нужные разделы.

## Настройки и доставка

Бот читает `.env` при первом запуске. Настройки, токены и очередь хранятся в `data/bot.sqlite3`. Держите `.env` и `data/` в приватном каталоге. Останавливайте бота перед резервным копированием каталога, а для замены отозванного токена Telegram используйте `python bot.py --setup`.

Интервал опроса по умолчанию составляет 60 секунд и меняется в админке. Базовая квота Lolzteam составляет 300 GET-запросов за 60 секунд. Бот ориентируется на квоту из ответа API и ждёт сброса, когда она исчерпана. Если тему поднимали несколько раз между проверками, API показывает последнее поднятие. [Лимиты Lolzteam](https://lolzteam.readme.io/reference/information#api-rate-limits)
